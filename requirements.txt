# Environmental monitoring dashboard - Python dependencies
# Install with:  .venv/bin/pip install -r requirements.txt
#
# System prerequisites (Raspberry Pi OS):
#   - I2C enabled:  sudo raspi-config nonint do_i2c 0   (or dtparam=i2c_arm=on in /boot/firmware/config.txt)
#   - user in the "i2c" group:  sudo usermod -aG i2c $USER
#   - optional, for bus scanning:  sudo apt install i2c-tools
#   - DS18B20 probe: 1-wire on GPIO17 -> add  dtoverlay=w1-gpio,gpiopin=17  to /boot/firmware/config.txt
#     and reboot. Read through the kernel's sysfs interface, so no extra Python package is needed.
